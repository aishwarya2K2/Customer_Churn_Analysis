# Customer_Churn_Analysis

## 🚀 Overview  
This project performs a comprehensive analysis of customer churn behavior, and builds a churn-prediction module to identify high-risk customers. The outcome is an interactive dashboard that helps businesses visualize churn patterns across demographics, tenure, payment methods, services used, and more.

---

## 🛠️ Tools & Technologies  
- Python (Pandas, NumPy, Scikit-learn)  
- SQL  
- Power BI(Dashboard & Visualization)  
- Data Cleaning & Exploratory Data Analysis (EDA)  
- Machine Learning (Prediction & Risk Scoring)   

---

## 🔍 EDA & Key Insights  
- Month-to-month customers have the highest churn rates.  
- Fiber optic internet users churn more compared to DSL users.  
- Short-tenure customers are more likely to churn than long-tenure ones.  
- Contract type and payment method strongly influence retention rates.  
*(More insights & charts included in the notebooks / dashboard)*

---

## 🔮 Prediction Module & Risk Scoring  
- Built a churn-prediction model to flag high-risk customers.  
- Output is a “Customers at Risk” view that businesses can use to proactively target retention efforts.  
- Combined with business-ready dashboard outputs for actionable decision-making.
